# APEX Wi-Fi access and recovery intent

Black State Group proposes the following capabilities for the Wi-Fi area of APEX in authorised client engagements.

1. Assess a protected Wi-Fi network when Black State is authorised to test it and the current password is unknown.
2. Use Pwnagotchi’s wireless authentication evidence in that assessment.
3. Recover the original Wi-Fi password where possible and determine whether access can be regained without already knowing it.
4. Verify the result on an authorised network by recording whether the original password was recovered and whether a device successfully joined.

These are proposed product outcomes. The [Wi-Fi status companion](WIFI_STATUS_PEER.md) covers the separate device status feature in draft PR #23.
