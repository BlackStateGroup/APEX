## Recovery boundaries

Four relevant historical conversations were recovered. The origin contains eight unavailable assistant bodies; three search excerpts recover substantial proposal text separately. The long setup reply ending the implementation conversation was returned in two contiguous segments, 0–1742 and 1742–2568; the archive concatenates only those exact bytes of text, without inserting an ellipsis or reconstructing missing wording. No guarantee is made that other branches, attachments, widgets or later edits are all represented. The 12-module interactive register was unavailable in the recovered proposal. Three earlier source suggestions lack names; their descriptions must not be used to invent repositories.

The latest user instructions are verbatim trusted conversation history, but their original IDs/permalink were not available to this pass. They use local references CURRENT-01 through CURRENT-04, explicitly not provider message IDs. No absent timestamp was guessed.

Historical assistant messages are included for an honest decision trail, including premature claims, old counts, Android-first proposals and admissions that work stopped. They do not override later user instructions or current evidence. For example: iPhone is now first-class; 31 recovered roots still do not mean all adapters are implemented; the DIY source’s own pinned technical note corrects an early broad NFC claim; importing REA reports did not satisfy active reverse engineering. Read [decision history](../DECISION_HISTORY.md) and [verified status](../VERIFIED_STATUS.md) alongside them.

## Privacy, access and retention

Only directly relevant APEX conversations are included. Unrelated conversations, private assistant notes, internal coordination, credentials, host environment dumps and raw connector response envelopes are excluded. This is intended for the owner's private APEX repository, not public publication. Conversation links may require the owner's original account and are not proof that other repository collaborators can open them. The embedded recovered text is the usable record if a link becomes inaccessible. Before widening repository access, review/redact personal conversation text and licensed source material.

Retain exact source text when adding records. Add an erratum or a new decision instead of rewriting an old quote. Attach original ID/URL and retrieval date where known; use null plus a clear reason when unknown. Record whether a statement is the user's instruction, an assistant proposal, historical report, observed result or unresolved question. Never turn a report of intent into evidence of completed engineering.
