# Memory-only HCI workbench

On Analysis, paste contiguous ASCII hex, declare synthetic/imported provenance, and explicitly Inspect metadata. Then explicitly select legacy reports or extended header metadata for a visible candidate. Loading the manually authored example only loads a draft/declaration. Nothing is automatically inspected or selected. Unsupported packets and extended advertising payloads stay opaque. Extended candidate classification is not validation.

The UI accepts at most 65536 hex characters (32768 decoded bytes), narrower than the core limit. No whitespace, separators, prefixes or normalization are accepted. Invalid/oversized edits are rejected whole, preserving the previous draft while clearing results and blocking Inspect. An accepted replacement or Clear removes this fence; declaration changes and tab transitions do not. Odd-length valid hex may remain during typing but inspection refuses it. Empty drafts also refuse inspection.

Metadata exposes four whole record summaries per page, including offsets, flags, truncation and producer-declared timestamps/drops. Candidate labels are not validation. Selection validates the whole legacy event before showing up to four reports per page. Nested AD strings are not projected at all: only AD framing status, issue/unparsed-byte counts, and service interpretation status counts are shown. BTHome complete, unsupported-object, malformed, limit-exceeded and opaque parse categories are counted separately. HCI framing acceptance does not imply AD or service decoding succeeded. Address/data strings exist only for the selected event, bounded by legacy limits and display excerpts. Separate scan responses are never pooled.

Prepared core handles and full selected summaries stay in private controller fields. Public state is deeply immutable and contains bounded pages only. Activation leases and generations fence late hashing success/failure; hashing is not cancelled. Render callbacks also require the exact observed state, preventing stale controls from acting after changes. Leaving Analysis clears prepared/selected data but retains draft/declaration/rejected-edit fence in memory. Reload loses all state.

SHA-256 is over the exact decoded supplied byte sequence, not the hex text. Web uses SubtleCrypto on a copied Uint8Array; native adapter uses installed Expo Crypto's byte-buffer digest, not its string API. Digest equality is not authenticated source, original pre-paste capture-byte identity, truthful capture history, ownership, receiver identity, physical reception or device identity. Host/controller records are not RF samples. Raw timestamps are producer claims; zero declared drops does not prove no loss. Resolved addresses need not be over-air addresses.

No file APIs, evidence persistence, journal, save/export/share/copy actions, device/radio access or provider calls are introduced. Tests use authored bytes only. Focused controller/static TSX and source-level native adapter checks are not mounted browser/native acceptance. The browser scenario is authored/listed only; prior socket/managed-localhost restrictions are not retried or bypassed.

## Explicit extended headers

The separate “Select extended HCI metadata” action validates the whole complete event before exposing a four-report page. It does not hash again or return source/payload bytes, parse AD, pool fragments or reassemble advertisements. Terminal complete may describe only the final fragment, not a whole advertisement. Structural acceptance is not exhaustive semantic legality; host feature support and scanner configuration remain unknown.

Each report displays exact report/data offsets and lengths, scalar field spans and raw numeric values, event flags/reserved bits, data status mask/shift, bounded exact state/meaning excerpts, PHY conditional meanings, SID, power, RSSI, interval, and diagnostics. Address spans are not formatted as MAC addresses when anonymous, reserved or inapplicable. Direct types 2/3 conditionally refer to TargetA or the corresponding scanner address, not a definite target identity. Address resolution does not establish physical identity. Current meanings fit the separate 192-character extended excerpt bound; other strings retain the 96-character bound.

Legacy and extended selection are mutually exclusive. A supported visible selection first clears both previous results, including on whole-event rejection. Editing, declaration changes, Clear, rejected edits and Analysis exit clear both kinds. Metadata and selected-report paging require the exact observed immutable state and current activation lease. Extended summaries contain only the deeply frozen core header tree, not prepared handles. Existing legacy AD/service/BTHome status summaries remain unchanged.

Authored source fixtures cover status 0/1/2/3 payload privacy, conditional states and address applicability, switching and late framing failure, pages/stale callbacks, nested freezing, all reset paths and late hash success/rejection. Actual TSX static rendering uses narrow host primitives, not browser/native acceptance. The added extended browser scenario is authored/listed only.
