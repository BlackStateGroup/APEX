# Offline synthetic lab walkthrough

With the repository's existing Node 24 setup, run from its root:

```sh
CI=1 EXPO_OFFLINE=1 EXPO_NO_TELEMETRY=1 npm_config_update_notifier=false npm_config_offline=true npm_config_audit=false npm_config_fund=false node tools/demo-offline-lab.ts
```

No arguments, installation, receiver, phone, provider or network access is needed. The command reads checked-in synthetic fixtures, generates digital samples in memory, and emits one compact JSON summary at most 12 KiB (currently 8,806 bytes including newline) only after every assertion succeeds. It writes no files, opens no journal/database, and performs no hardware operations. Failure exits nonzero with empty stdout. All timestamps are fixed demonstration values, not execution times or reception evidence.

## What runs together

1. Prepare and retain the exact first selected-source document in `tests/fixtures/ble-differential.json`. Reinterpret its Android AD bytes as public BTHome v2 temperature 20 °C. A complete format interpretation is not authentication, sensor truth or physical reception.
2. Explicitly author the existing eight trials and compare them, preserving the two separately declared Android/iOS sources; only payload offset 2 changes in each source. Check the existing candidate in `ble-field-hypothesis.json`: exact rational values 20 and 461/25 (18.44), all eight matching. Synthetic discovery/held-out declarations do not establish independent blinding, causation or identity.
3. Interpret the existing serialized NDEF greeting as inert `Hi`. No tag reading/writing, URL dispatch or action execution occurs.
4. Save those exact BLE/NDEF documents through the real `EvidenceStore` with an array-backed, memory-only backend. Select the two stored documents in explicit reverse order, create a bundle and verify its preview and exact text retention. Digests detect content mismatch, but are not signatures or trusted timestamps. The bundle itself is not written or exported.
5. Generate 512 `ci16_le` complex samples at a declared 1024 samples/second. Check a +64-bin, 0.5-amplitude FFT peak, two matching time-frequency frames, exact energy sums and strict threshold equality (not above). Test lags 1–4: all have unit normalized squared magnitude. A constant complex tone therefore does not identify a period from magnitude alone. These are digital diagnostics, not calibrated RF measurements, demodulation or protocol identification.

6. Explicitly select two phase pairs for each lag 1, 2 and 4, starting at sample 0 with step 4. Verify `right * conjugate(left)` products `(0, 268435456)`, `(-268435456, 0)` and `(268435456, 0)` and endpoint energies `268435456`, all exact raw-count decimal strings. Principal phases are approximately pi/2, pi and zero, giving declared-rate offsets 256, 256 and zero Hz. Alias spacings are 1024, 512 and 256 Hz, with principal intervals (-512,512], (-256,256] and (-128,128]. The lag-4 zero phase aliases the same nonzero quartertone; it is not a zero-energy endpoint. Actual zero-energy endpoints would have unavailable phase/frequency, not a numeric zero. These nonzero fixtures do not exercise that separate core branch. Full original metadata/data SHA-256 hashes are retained, rather than hashes of selected pairs. Nothing estimates a carrier, unwraps phase or establishes radio compatibility.
7. Inspect three manually authored, nonprivileged version-response frames declared synthetic. The inline bytes are not an upstream fixture or device capture. Assert omitted versus explicit-zero versus decode-error status, absent command ID and continuation defaults, and present/absent version scalars. Effective zero is not reported success when omitted; even explicit zero establishes no identity, request correlation, completion or Flipper compatibility. Only version content is present; no identity-success inference is made.

8. Inspect `tests/fixtures/offline-lab.ir`, an original manually authored 620-byte ASCII file. Retain/hash the exact source. Distinguish declared standard NEC fields (address 33, command 69) from conditional whole-array recognition of 67 alternating durations and an unrecognized three-duration partial array. Frequency 38000 Hz and duty cycle decimal 0.33 are declarations, not measured carrier properties; repeats are not represented. No duration dump, physical capture, identity or compatibility claim is emitted.
9. Inspect the original manually authored 187-byte btsnoop/H4 container encoded in `tests/fixtures/offline-lab-hci.hex`. Hash the full decoded container, including opaque content. List metadata for an opaque command, one explicitly selected legacy event containing separate advertisement and scan-response reports, and one explicitly selected extended metadata event. Legacy known synthetic AD bytes are `020106` and empty, with independent RSSI values -50 and -60; the shared address is not identity evidence. Extended data is entirely omitted; terminal complete can be only the final fragment. PHY bytes 3/4 have unknown feature context, TxPower 127 is unavailable, and RSSI 129 is signed -127. Private synthetic marker bytes in opaque command and extended data never appear in reports. No AD interpretation of extended bytes, pooling or reassembly occurs. Signed raw timestamps -10/-9/-8 are producer claims; zero cumulative drops does not establish no losses. Host/controller bytes are not BLE-PLX or physical RF samples, and hash equality establishes byte equality only.

These added stages import only the existing pure offline analyzers. They acquire no bytes, permissions, provider, transport, device or network resources. Results demonstrate synthetic software behavior, not phone/native/radio/Flipper compatibility.

## Real input is a separate workflow

Do not edit these fixture origins or relabel them as captured data. For operator-authorized imported files, use the existing explicit imported-file flows separately: `docs/BLE_DIFFERENTIAL_EXPERIMENT.md`, `docs/BLE_FIELD_HYPOTHESIS.md`, `docs/NDEF_OFFLINE.md`, and `docs/OFFLINE_IQ_INSPECTION.md`. Retain original bytes/documents and declare `recorded-import` provenance honestly. Supplier metadata and receipt labels remain caller claims. The walkthrough intentionally accepts no file argument, so an external file cannot accidentally be presented as its synthetic reference.

Native build/device QA, permissions and lifecycle behavior, physical BLE/NFC reception, receiver integration, calibrated RF validation and independently controlled experiments remain separate pending gates. This demonstration does not discharge them and adds no control, decryption, pairing, connection or identity capability.

## Host regression

`node --test --test-concurrency=2 tests/offline-lab-walkthrough.test.ts` invokes the real CLI under Node filesystem permissions allowing reads but no writes, checks its complete parseable bounded deterministic output, synthetic origin and memory-only storage, and injects failures after early stages and during late phase arithmetic and Flipper status assertions to verify that no partial success is printed.

`node --test tests/offline-lab*.test.ts` also checks independent IR integer and HCI byte-offset/hash oracles, late IR/HCI failures, and final serialization/size failures with empty stdout. A targeted preload traps common Node network entry points; this is not an OS-level network-isolation claim. Tests retain the existing output bound's intent: compact summaries, not full duration arrays or opaque payloads.
