Environment additions: compiler target x86_64-linux-gnu; glibc 2.41 (Debian 2.41-12+deb13u4). Baseline optimized executable 39,600 bytes; frozen optimized executable 166,664 bytes. These sizes are build-specific, not mobile size estimates. Executables are excluded from the source archive.

Canonical APEX source hash check after all work showed unchanged core snapshots, and git status of the canonical checkout was clean at the time checked. No canonical application, lockfile, firmware or source file was edited by this experiment.
